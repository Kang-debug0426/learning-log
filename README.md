# learning-log

12 周 RAG + Agent 工程师之路的学习日记 + 踩坑沉淀。

> 起跑：2026-05-28（W1 D1）
> 节奏：12 周 × 5 天/周 × 5-7h/天
> 模式：B 模式（看课→暂停→自写→对照） + C 模式（复刻→换数据魔改）

## 目录

| 目录 | 用途 |
|------|------|
| `daily/` | 每日日记，文件名 `YYYY-MM-DD.md` |
| `weekly/` | 周复盘，文件名 `weekNN-review.md` |
| `notes/` | 横向笔记（某个工具/概念专项整理） |

## 日记结构

每天一篇，4 个固定字段：

- **今日目标**（开工前写）
- **完成情况**（收工前写）
- **踩坑记录**（遇到就记，含根因 + 一句话教训）
- **明日计划**（睡前写）
